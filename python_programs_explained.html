1. What is Artificial Intelligence?

Definition: AI is the ability of a machine to perform tasks that normally require human intelligence—such as recognizing patterns, making decisions, and solving problems.

2. The 5 Core Components of a Search Problem

Every search problem in AI breaks down into exactly 5 pieces:

  • Initial State: The starting point of the agent.
  • Goal State: The target state to achieve.
  • State Space: The set of all valid states reachable from the start.
  • Operators / Actions: Valid moves that transition the agent between states.
  • Path Cost: A numeric value reflecting distance, time, or energy spent.

3. Search Terminology

  • Node: An individual element or state in the search tree.
  • Tree: A structure in which nodes are connected in a hierarchical manner (Parents and Children).
  • Successor: States generated from another state by applying an action.
  • State Space Representation: A mathematical or graphical model (using nodes and edges) that represents states and their transitions.

4. Blind / Uninformed Search

Definition: A search technique that does not use any additional information or "heuristics" about how close a state is to the goal. Imagine trying to find a specific house in a new city without a map or GPS; you just have to check every street systematically.

  • The algorithm blindly explores available states solely based on the order they are generated.
  • It does not know if a specific move is "good" or "bad", it only knows if it has reached the target or not.
  • Examples: BFS (Breadth-First Search), DFS (Depth-First Search), DLS (Depth-Limited Search), and IDS (Iterative Deepening Search).

5. The 4 Core Blind Search Algorithms

These are the most important uninformed search strategies. Each explores the State Space differently:

  • BFS (Breadth-First Search):
    • How it explores: Level-by-level. It checks all immediate children (neighbors) first before moving deeper into the tree. It searches "wide".
    • Data Structure: Queue (FIFO — First-In, First-Out).
    • Advantage: Always guaranteed to find the shortest path to the goal.
  • DFS (Depth-First Search):
    • How it explores: Goes as deep as possible down a single path until it hits a dead end, then backtracks to try the next path. It searches "deep".
    • Data Structure: Stack or Recursion (LIFO — Last-In, First-Out).
    • Advantage: Requires significantly less memory than BFS because it only needs to store the current single path being explored.
  • DLS (Depth-Limited Search):
    • How it explores: It is exactly like DFS, but with a strict "Depth Limit". Once it reaches that depth, it forces the algorithm to stop and backtrack, even if it hasn't hit a dead end yet.
    • Data Structure: Stack or Recursion (with a depth counter variable).
    • Advantage: Solves the biggest problem of DFS by preventing the algorithm from getting stuck forever in an infinite loop or an infinitely deep path.
  • IDS (Iterative Deepening Search):
    • How it explores: It combines the best of BFS and DFS. It simply runs DLS repeatedly, increasing the allowed Depth Limit by 1 each time (Depth 0, then Depth 1, then Depth 2...) until the goal is found.
    • Data Structure: Stack or Recursion (repeatedly cleared and reused).
    • Advantage: It gives you the "Shortest Path Guarantee" of BFS while maintaining the "Low Memory Consumption" of DFS. It is the best of both worlds!

1. Write a program to implement Breadth First Search (BFS) for the Monkey Banana Problem.

from collections import deque 
 
queue = deque(["Monkey at Door"]) 
visited = [] 

while queue: 
    state = queue.popleft() 
 
    if state not in visited: 
        visited.append(state) 
        print(state) 
 
        if state == "Monkey at Door": 
            queue.append("Monkey at Box") 
        elif state == "Monkey at Box": 
            queue.append("Box Under Banana") 
        elif state == "Box Under Banana": 
            queue.append("Monkey Climbs Box") 
        elif state == "Monkey Climbs Box": 
            queue.append("Monkey Gets Banana") 
        elif state == "Monkey Gets Banana": 
            print("\nGoal : Banana Obtained!") 
            break

Algorithm Steps:

  1. Initialize: Define the starting state (S0: Monkey at Door).
  2. Enqueue: Push the starting state into a FIFO Queue.
  3. Loop: While the queue is not empty, remove (pop) the front state.
  4. Goal Check: If the current state is the Goal (Monkey Gets Banana), stop searching.
  5. Expand: If not the Goal, find the logical Next State (Successor).
  6. Repeat: Push the Next State into the Queue and continue the loop.

2. Write a program to solve the Water Jug Problem using BFS.

from collections import deque

def water_jug():
    visited = set()
    queue = deque([((0, 0), [(0, 0)])])

    while queue:
        (x, y), path = queue.popleft()

        if (x, y) in visited: continue
        visited.add((x, y))

        if x == 2 or y == 2:
            print("Solution Path:")
            for state in path: print(state)
            return

        states = [
            (4, y), (x, 3), (0, y), (x, 0),
            (max(0, x - (3 - y)), min(3, x + y)),
            (min(4, x + y), max(0, y - (4 - x)))
        ]

        for s in states:
            if s not in visited:
                queue.append((s, path + [s]))

water_jug()

Algorithm Steps:

  1. Initialize: Start with both jugs empty (0, 0) and push this state into a Queue.
  2. Loop: Dequeue the front state. If it's already visited, skip it. Otherwise, mark it visited.
  3. Goal Check: If either jug contains exactly 2 liters, print the path and stop.
  4. Expand: Generate all valid next states by applying the 6 operators (Fill 4L, Fill 3L, Empty 4L, Empty 3L, Pour 4L→3L, Pour 3L→4L).
  5. Repeat: Push all unvisited next states into the Queue and repeat.

4. Write a program to solve a state-space search problem using BFS.

# State Space Tree:
#
#             Start
#            /     \
#      State_1     State_2
#      /     \     /     \
#  State_3 State_4 State_5 Goal
#             \
#             Goal

from collections import deque

state_space = {
    'Start': ['State_1', 'State_2'],
    'State_1': ['State_3', 'State_4'],
    'State_2': ['State_5', 'Goal'],
    'State_3': [],
    'State_4': ['Goal'],
    'State_5': [],
    'Goal': []
}

def bfs_search(initial_state, goal_state):
    visited = set()
    queue = deque([(initial_state, [initial_state])])
    
    while queue:
        current_state, path = queue.popleft()
        
        if current_state in visited: continue
        visited.add(current_state)
        
        if current_state == goal_state:
            print("Goal Found! Path:", " -> ".join(path))
            return
            
        for next_state in state_space.get(current_state, []):
            if next_state not in visited:
                queue.append((next_state, path + [next_state]))

bfs_search('Start', 'Goal')

#               /   \

#             / \     \

#                ↑
#             Target

def dls(graph, node, target, limit, visited):
    if node == target:
        return True
    
    if limit <= 0:
        return False
        
    visited.add(node)
    
    for neighbour in graph.get(node, []):
        if neighbour not in visited:
            if dls(graph, neighbour, target, limit - 1, visited.copy()):
                return True
                
    return False

2. Write a program to solve the Missionaries and Cannibals Problem.

from collections import deque

def is_valid(m_left, c_left):
    m_right, c_right = 3 - m_left, 3 - c_left
    if m_left > 0 and m_left < c_left: return False
    if m_right > 0 and m_right < c_right: return False
    return True

def solve():
    initial = (3, 3, 0)
    goal = (0, 0, 1)
    queue = deque([(initial, [initial])])
    visited = set()
    moves = [(1, 0), (2, 0), (0, 1), (0, 2), (1, 1)]

    while queue:
        (m_left, c_left, boat), path = queue.popleft()

        if (m_left, c_left, boat) in visited: continue
        visited.add((m_left, c_left, boat))

        if (m_left, c_left, boat) == goal:
            print("Solution:"); 
            for s in path: print(s)
            return

        for m, c in moves:
            if boat == 0:
                new_m, new_c, new_boat = m_left - m, c_left - c, 1
            else:
                new_m, new_c, new_boat = m_left + m, c_left + c, 0

            if 0 <= new_m <= 3 and 0 <= new_c <= 3:
                if is_valid(new_m, new_c):
                    new_state = (new_m, new_c, new_boat)
                    if new_state not in visited:
                        queue.append((new_state, path + [new_state]))
solve()

Algorithm Steps:

  1. Initialize: Start with 3 Missionaries and 3 Cannibals on the left bank (3, 3, 0). Push to Queue.
  2. Loop: Dequeue the current state and mark it visited.
  3. Goal Check: If all are on the right bank (0, 0, 1), print the solution path and stop.
  4. Generate Moves: Try all 5 possible boat moves (1M, 2M, 1C, 2C, 1M+1C).
  5. Validate: Ensure the boat move is valid (Cannibals don't outnumber Missionaries on either bank).
  6. Repeat: Push valid, unvisited states to the Queue and continue.

3. Write a program to solve the Tower of Hanoi Problem using state-space representation.

from collections import deque

def get_successors(state):
    successors = []
    # State represents 3 pegs A, B, C as lists of disk sizes
    for i in range(3):
        if not state[i]: continue
        disk = state[i][-1]
        
        for j in range(3):
            if i == j: continue
            # Can place if peg is empty or top disk is larger
            if not state[j] or state[j][-1] > disk:
                new_state = list(list(peg) for peg in state)
                new_state[i].pop()
                new_state[j].append(disk)
                successors.append(tuple(tuple(peg) for peg in new_state))
    return successors

def solve_hanoi():
    initial = ((3, 2, 1), (), ())
    goal = ((), (), (3, 2, 1))
    
    queue = deque([(initial, [initial])])
    visited = {initial}
    
    while queue:
        state, path = queue.popleft()
        if state == goal:
            print(f"Solution Found in {len(path)-1} steps!")
            for p in path: print(p)
            return
            
        for succ in get_successors(state):
            if succ not in visited:
                visited.add(succ)
                queue.append((succ, path + [succ]))

solve_hanoi()

Algorithm Steps:

  1. Initialize: Start with all disks on Peg A ((3, 2, 1), (), ()) and push to Queue.
  2. Loop: Dequeue the front state.
  3. Goal Check: If all disks are on Peg C in order ((), (), (3, 2, 1)), print steps and stop.
  4. Expand: For each peg, check if the top disk can be legally moved to another peg (only if the target peg is empty or has a larger top disk).
  5. Repeat: Push all legal new states into the Queue, mark as visited, and repeat.

4. Write a program implement Iterative Deepening Search (IDS).

def dls(graph, node, target, limit):
    if node == target: return True
    if limit <= 0: return False
    
    for neighbour in graph.get(node, []):
        if dls(graph, neighbour, target, limit - 1):
            return True
    return False

def ids(graph, start, target, max_depth):
    for limit in range(max_depth + 1):
        print(f"Searching at depth limit {limit}...")
        if dls(graph, start, target, limit):
            print(f"Target '{target}' found at depth limit {limit}!")
            return True
    print("Target not found.")
    return False

graph = {
    'A': ['B', 'C'],
    'B': ['D', 'E'],
    'C': ['F'],
    'D': [],
    'E': [],
    'F': []
}
ids(graph, 'A', 'E', 3)

Algorithm Steps:

  1. Initialize: Start with a Depth Limit of 0.
  2. Run DLS: Perform a Depth-Limited Search (DLS) from the Start Node.
  3. Goal Check: If DLS finds the Target Node within the current limit, stop and return True.
  4. Iterate: If the Target is not found, increase the Depth Limit by 1 (limit = limit + 1).
  5. Repeat: Restart DLS from the beginning with the new, deeper limit. Repeat until the target is found or maximum depth is reached.

5. Write a program to analyze the time and space complexity of BFS.

import time
from collections import deque

def generate_tree(branch_factor, depth):
    graph = {}
    nodes = 1
    def build(node, d):
        nonlocal nodes
        graph[node] = []
        if d < depth:
            for _ in range(branch_factor):
                nodes += 1
                child = f"N{nodes}"
                graph[node].append(child)
                build(child, d + 1)
    build("Root", 0)
    return graph, nodes

def measure_bfs(graph, start):
    queue = deque([start])
    visited = set([start])
    max_q = 0
    start_t = time.time()
    
    while queue:
        max_q = max(max_q, len(queue))
        node = queue.popleft()
        for neighbour in graph[node]:
            if neighbour not in visited:
                visited.add(neighbour)
                queue.append(neighbour)
                
    end_t = time.time()
    return (end_t - start_t), max_q

b, d = 3, 5
graph, total = generate_tree(b, d)
time_taken, max_space = measure_bfs(graph, "Root")

print(f"Nodes: {total}")
print(f"Time (seconds): {time_taken:.5f}")
print(f"Space (Max Queue Size): {max_space}")

Algorithm Steps (Complexity Analysis):

  1. Setup: Generate a massive state-space tree with a fixed branching factor (e.g., 3) and depth (e.g., 5).
  2. Start Timer: Record the start time just before BFS begins.
  3. Track Space: During BFS, continuously check the length of the Queue. Record the maximum length reached (This represents Space Complexity).
  4. Stop Timer: Record the end time when BFS completes (This represents Time Complexity).
  5. Analyze: Output the Total Nodes processed, Execution Time (Time Complexity), and Max Queue Size (Space Complexity).
