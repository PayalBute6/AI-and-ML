AI Problem Solving & Search

1. What is Artificial Intelligence?

Definition: AI is the ability of a machine to perform tasks that normally require human intelligence—such as recognizing patterns, making decisions, and solving problems.

Daily Examples: Instagram recommendation feed, Google Maps pathfinding, chess bots.

2. The 5 Core Components of a Search Problem

Every search problem in AI breaks down into exactly 5 pieces:

Component Plain English Meaning Real-Life (Home to College) AI Technical Term
1. Initial State Where do we start right now? At home Initial State
2. Goal State Where do we want to finish? College classroom Goal State
3. State Space Every possible location we could visit Home, Bus Stop, Chowk, Station, College State Space
4. Operators (Actions) What actions move us from place to place? Walk, Take Bus, Turn Left Operators / Actions
5. Path Cost What does taking that path cost us? 5 km distance or 25 minutes time Path Cost

Key Confusion to Fix Early

  • State Space: The entire collection of all possible locations/situations.
  • State Space Representation: The actual diagram (nodes and lines) you draw on paper or code into a computer to show those states and moves.

3. The 6 Steps in AI Problem Solving

  1. Define the Problem: "I need to reach college before 9:00 AM."
  2. Determine Initial State: "I am standing at my front door."
  3. Define Goal State: "Inside the AI lab."
  4. Generate Potential Actions: "Can I walk? Take a bus? Take an auto?"
  5. Find the Solution Path: "The bus route is fastest today—select that sequence of stops."
  6. Implement the Solution: "Actually take the bus (execute the Python script)."

2. What does "Blind Search" mean?

Blind / Uninformed Search: A search technique that does not use additional information or a heuristic about how close a state is to the goal.
Marathi: Blind Search म्हणजे goal कुठे आहे किंवा कोणता state goal च्या जवळ आहे याची extra information न वापरता search करणे.

Computer basically says: "मला कोणता मार्ग योग्य आहे हे आधीपासून माहीत नाही. मी available states तपासत जातो."

3. BFS — Breadth First Search

Now introduce the full form: BFS = Breadth First Search

Simple Definition: BFS is a search algorithm that explores nodes level by level.
Marathi: BFS ही अशी search technique आहे जी tree मधील nodes एक-एक level पूर्ण करून पुढील level वर जाते.

4. What is "Level by Level"?

A / \ B C / \ / \ D E F G

Now divide it into levels:

Level 0 A Level 1 B C Level 2 D E F G

BFS first visits A, then B C, then D E F G.

BFS traversal: A → B → C → D → E → F → G

Marathi: BFS मध्ये आधी Level 0, मग Level 1, मग Level 2 अशा क्रमाने nodes visit केले जातात.

5. What is a Node?

A node is an individual element/state in the search tree. In our example, A, B, C, D, etc. are nodes.

Marathi: Tree मधील प्रत्येक individual element/state ला Node म्हणतात.

6. What is a Tree?

A tree is a structure in which nodes are connected in a hierarchical manner.

A → Parent B,C → Children of A D,E → Children of B F,G → Children of C

7. The MOST IMPORTANT Concept — Queue

"BFS uses a Queue." It uses a FIFO (First In, First Out) approach.

8. What is a Queue?

Imagine students standing in a queue. Who gets served first? Student A, because A entered first.

FIFO — First In, First Out
Marathi: Queue म्हणजे रांग. जो student आधी रांगेत आला तो आधी बाहेर/serve होतो. म्हणून FIFO = First In First Out.

9. Why Does BFS Use Queue?

Queue processing steps automatically process nodes level by level:

  • Start: Queue = [A]
  • Remove A, Add children: Queue = [B, C]
  • Remove B, Add children: Queue = [C, D, E]
  • Remove C, Add children: Queue = [D, E, F, G]

10. BFS Step-by-Step

Initial State = A | Goal = G

Step 1: Visit A. Queue = [B, C] Step 2: Visit B. Queue = [C, D, E] Step 3: Visit C. Queue = [D, E, F, G] Step 4: Visit D. Step 5: Visit E. Step 6: Visit F. Step 7: Visit G. (Goal found! STOP)
Important distinction:
Traversal order: A → B → C → D → E → F → G
Solution path to G: A → C → G

11. BFS Algorithm

1. Start with the initial state. 2. Put the initial state into the queue. 3. Remove the first state from the queue. 4. Check whether it is the goal state. 5. If it is the goal, stop. 6. Otherwise, generate its successor states. 7. Add unvisited successors to the queue. 8. Repeat until the goal is found or queue is empty.
Marathi:
1. Initial state घ्या.
2. तो Queue मध्ये टाका.
3. Queue मधील पहिला node काढा.
4. तो Goal आहे का ते तपासा.
5. Goal असेल → Stop.
6. Goal नसेल → त्याचे successor states शोधा.
7. Unvisited states Queue मध्ये टाका.
8. Goal मिळेपर्यंत repeat करा.

12. What is a Successor?

States generated from another state by applying an action.

Marathi: एखाद्या state वर action केल्यानंतर मिळणाऱ्या पुढील states ना Successor States म्हणतात.

Practical 1: Monkey-Banana Problem using Breadth-First Search (BFS)

1. Problem Definition & Physical Setup

A hungry monkey enters a room with high ceilings:

  • Bananas hang suspended from the ceiling in the middle of the room, out of the monkey's direct reach.
  • A heavy Box is located at another spot in the room (near the window).
  • The monkey can only reach the bananas if it pushes the box directly under the bananas, climbs on top of it, and grabs them.
[ Position A: Door ] [ Position C: Middle ] [ Position B: Window ] (Monkey starts) (Bananas on ceiling) (Box starts)

4. Complete Python Implementation

from collections import deque # Step 1: Initialize the FIFO queue with the initial state S0 queue = deque(["Monkey at Door"]) # Step 2: Track visited states to prevent redundant cycles visited = [] # Step 3: Run the BFS loop while the queue has pending states while queue: # Remove the front state (FIFO: First-In, First-Out) state = queue.popleft() if state not in visited: visited.append(state) print(state) # Transition logic based on current state if state == "Monkey at Door": queue.append("Monkey at Box") elif state == "Monkey at Box": queue.append("Box Under Banana") elif state == "Box Under Banana": queue.append("Monkey Climbs Box") elif state == "Monkey Climbs Box": queue.append("Monkey Gets Banana") elif state == "Monkey Gets Banana": print("\nGoal: Banana Obtained!") break

Expected Terminal Output

Monkey at Door Monkey at Box Box Under Banana Monkey Climbs Box Monkey Gets Banana Goal: Banana Obtained!

5. Line-by-Line Code Explanation

  • from collections import deque
    Imports the double-ended queue class from Python's standard library. Unlike standard Python lists which require O(n) time to remove elements from the start, deque executes popleft() in optimal O(1) constant time.
  • queue = deque(["Monkey at Door"])
    Initializes the search frontier with the single starting state S0.
  • visited = []
    An explored list tracking every expanded state, guaranteeing no state is processed multiple times.
  • while queue:
    Continues the search frontier exploration as long as elements remain in the queue.
  • state = queue.popleft()
    Pulls the oldest element from the front, enforcing strict BFS FIFO ordering.
  • if state == "Monkey Gets Banana": ... break
    Validates whether the extracted state satisfies the goal condition. If true, prints the success message and terminates the algorithm.

7. Essential Viva-Voce Questions

  1. What type of search algorithm is BFS?
    Answer: It is an Uninformed (Blind) Search algorithm because it traverses the state space without using any heuristic or cost-to-goal estimation.
  2. Why does BFS require a Queue instead of a Stack?
    Answer: A Queue strictly enforces FIFO (First-In, First-Out), ensuring nodes are expanded level-by-level (shallowest nodes first). A Stack implements LIFO, which turns the search into DFS (Depth-First Search).
  3. What is the state transition sequence in the Monkey-Banana problem?
    Answer: S0 (At Door) → S1 (At Box) → S2 (Box Under Banana) → S3 (Climb Box) → S4 (Grab Banana).
  4. What is the time and space complexity of BFS?
    Answer: Both time complexity and space complexity are O(bd), where b is the branching factor and d is the depth of the shallowest goal.
