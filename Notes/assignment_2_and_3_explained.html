ASSIGNMENT 2 Informed Search Techniques

Key Concept: Informed search uses domain-specific heuristic knowledge $h(n)$ to estimate the remaining cost to the goal.
  • Evaluation Function: $f(n) = g(n) + h(n)$ for A*, and $f(n) = h(n)$ for Greedy BFS.
  • Admissible Heuristic: Never overestimates the true minimal cost to the goal ($h(n) \le h^*(n)$). Guarantees A* optimality.
  • Consistent / Monotonic Heuristic: Satisfies $h(n) \le c(n, a, n') + h(n')$.

Set A.1 Best First Search using Heuristic Values

Problem: Write a program to implement the Best First Search Algorithm using heuristic values to find a path from a start node to a goal node. (File: best_first_search.py)

from queue import PriorityQueue graph = { 'A': ['B', 'C'], 'B': ['D', 'E'], 'C': ['F', 'G'], 'D': [], 'E': [], 'F': [], 'G': [] } heuristic = {'A': 10, 'B': 8, 'C': 5, 'D': 7, 'E': 6, 'F': 2, 'G': 0} def best_first_search(start, goal): visited = set() pq = PriorityQueue() pq.put((heuristic[start], start, [start])) while not pq.empty(): h, current, path = pq.get() if current in visited: continue visited.add(current) if current == goal: print("Goal Found!") print("Path:", " -> ".join(path)) return path for neighbor in graph[current]: if neighbor not in visited: pq.put((heuristic[neighbor], neighbor, path + [neighbor])) best_first_search('A', 'G')

Algorithm Steps:

  1. Initialize a Priority Queue with the starting node ordered by heuristic value $h(start)$.
  2. Extract the node with the lowest heuristic value $h(n)$ from the queue.
  3. If the current node equals the Goal, terminate and return the reconstructed path.
  4. Otherwise, expand all unvisited successors, evaluate their heuristics, and insert them into the priority queue.
  5. Repeat until the goal is found or the queue is exhausted.

Sample Output:

Goal Found! Traversal Order: A -> C -> G Solution Path : A -> C -> G

Set A.2 A* Search Algorithm for Shortest Path

Problem: Write a program to implement the A* Search Algorithm to find the shortest path between a source node and a destination node. (File: astar_search.py)

import heapq graph = { 'A': {'B': 1, 'C': 4}, 'B': {'D': 2, 'E': 5}, 'C': {'F': 3}, 'D': {'G': 3}, 'E': {'G': 1}, 'F': {'G': 2}, 'G': {} } heuristics = {'A': 6, 'B': 5, 'C': 4, 'D': 3, 'E': 2, 'F': 2, 'G': 0} def a_star_search(start, goal): start_f = 0 + heuristics[start] open_queue = [(start_f, 0, start, [start])] best_g = {start: 0} visited = set() while open_queue: f, g, current, path = heapq.heappop(open_queue) if current in visited: continue visited.add(current) if current == goal: print("Optimal Path:", " -> ".join(path)) print("Optimal Cost:", g) return path, g for neighbor, cost in graph[current].items(): new_g = g + cost new_f = new_g + heuristics[neighbor] if neighbor not in best_g or new_g < best_g[neighbor]: best_g[neighbor] = new_g heapq.heappush(open_queue, (new_f, new_g, neighbor, path + [neighbor])) a_star_search('A', 'G')

Algorithm Steps:

  1. Initialize Priority Queue with $(f, g, start, path)$ where $g = 0$ and $f = g + h(start)$.
  2. Pop the node with the minimum $f(n)$ value.
  3. If the popped node is the Goal, return the optimal path and true cost $g$.
  4. For each neighbor, calculate $g(neighbor) = g(current) + cost$ and $f(neighbor) = g(neighbor) + h(neighbor)$.
  5. If this new path offers a lower $g$-value to neighbor, update its cost and push it to the priority queue.

Sample Output:

Optimal Path: A -> B -> D -> G Optimal Cost: 6

ASSIGNMENT 3 Constraint Satisfaction Problems (CSP)

CSP Definition: A problem defined by a triplet $(X, D, C)$:
  • Variables ($X$): $X = \{X_1, X_2, \dots, X_n\}$
  • Domains ($D$): $D_i$ is the set of allowable values for variable $X_i$.
  • Constraints ($C$): Restrictions specifying allowable combinations of variable assignments.
